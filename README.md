# Rule-Based AI Chatbot

## Project Overview

This project is a simple Rule-Based AI Chatbot developed using Python.

The chatbot uses predefined rules and if-else decision-making to understand specific user inputs and provide suitable responses.

## Features

- Responds to greetings
- Introduces itself
- Answers basic questions about AI
- Explains what a chatbot is
- Provides simple study help
- Gives motivation
- Tells a joke
- Responds to compliments and feelings
- Answers basic programming questions
- Explains how it works
- Supports exit commands such as `bye`, `exit`, and `quit`

## Technologies Used

- Python
- If-Else Statements
- While Loop
- String Handling
- User Input

## How It Works

The chatbot continuously takes input from the user.

It converts the input to lowercase and removes unnecessary spaces. Then, it checks the input against predefined conditions using `if`, `elif`, and `else` statements.

If a matching rule is found, the chatbot gives the corresponding response.

If no matching rule is found, it displays a default response.
